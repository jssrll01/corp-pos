# RestoPOS User Guide

## First time
1. Open the app and enter your business name and activation key.
2. Menu (three lines, top left) > Management. Default PIN is 1234. Change it in Settings.
3. Settings: display name, logo, currency, tax, receipt address, phone and footer.
4. Products: add name, price, barcode, image, optional stock.

## Making a sale
1. Menu > Cash Register. Tap products or type a name or scan a barcode in the search bar and press Enter.
2. Tap View Order. Adjust quantity, set a discount (% or fixed), choose payment method.
3. For cash, enter cash received (or tap Exact). Change shows automatically.
4. Add an optional note, then Complete Sale.
5. Print 58mm or 60mm, then Done.

## Orders
Menu > Orders shows top sellers and history. Tap an order to see details or reprint.

## Backup (do this weekly)
Management > Data > Download full backup (JSON). Restore from the same screen.

## Install
Use the Install button in the top bar, or the browser menu > Add to Home screen. The app then works offline.
